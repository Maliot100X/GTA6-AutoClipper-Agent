# SEO / publishing pack format

Every clip gets one `publish-pack.md` (see the real one in [examples/clip-2026-11-20/publish-pack.md](../examples/clip-2026-11-20/publish-pack.md)). One section per account:

| Field | YouTube Shorts | Instagram Reels | Facebook Reels | TikTok |
|---|---|---|---|---|
| Title | ≤ 100 chars, keyword first, `#Shorts` | — (first line of caption) | first line | first line |
| Description / caption | hook line, what happens, **creator credit + source link**, fan disclaimer | same, shorter, line breaks | same | short, punchy |
| Hashtags | 3-5 (`#GTA6 #GTAVI #Shorts`) | 5-10 | 3-5 | 3-6 incl. `#fyp` style |
| Category | Gaming (set in Studio) | — | — | — |
| Keyword block | **top-50 keywords** under the description | top-50 block after hashtags | top-50 block | top-50 block |
| Tags | 28 tags, ≤ 500 chars (paste in Studio) | — | — | — |

Keyword sources, in order: vidIQ keyword research → trendspy (Google Trends) → TubeAlfred search on today's top GTA 6 Shorts → YouTube Data API titles of the top 25 videos (last 24 h) → skills `youtube-seo`, `seo-title-optimization`, `hashtag-strategy`, `social-seo`, `instagram-seo`, `tiktok-growth`, `youtube-shorts`, `sms-hook-writer`.

## Rules
- No story spoilers in titles/thumbnails (free roam footage preferred).
- Never write "official"; always "Unofficial fan clip, not affiliated with Rockstar Games."
- Credit the creator by name and link the source VOD in every caption.
